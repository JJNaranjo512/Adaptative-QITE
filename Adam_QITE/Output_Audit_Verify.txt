g5 -- the free error estimator vs R1 step-doubling  [[G5_Error_Estimator_Validated_And_Its_Blind_Spot]]
========================================================================================

  Y_k = -dE/dtheta_k exactly, so dE_pred = -Y.theta_dot delta_tau is the exact first-order
  Taylor term and |dE_actual - dE_pred| is a genuine O(delta_tau^2) local-error proxy -- already
  computed by energy_check on every step, then discarded. The README asserts this premise and
  never tests it. V2 tests it against the step-doubling estimator R1 proposes, which costs a
  whole extra measure_f per step.

  Step-doubling algebra predicts the ratio exactly: the full step errs by ~C dtau^2 and two half
  steps by ~2C(dtau/2)^2 = C dtau^2 / 2, so their difference is C dtau^2 / 2 -- half of what
  |dE_actual - dE_pred| ~ C dtau^2 measures. The prediction is a constant ratio of 2.

g6-2 -- the ratchet degeneracy  [[G6_Attribution_And_Reproducibility]] section 6.2
========================================================================================

  G6 section 6.2 records that beta1 = beta2 = 0 with a large k_I collapses the Adam controller
  onto Route 3's plain ratchet exactly, and notes this claim had no code path -- the same defect
  as the project-wide audit's F3. It does now.

  Why it is exact, in one line: with beta1 = 0 the EMA keeps only the current sample, and the
  bias correction c1 = 1 - 0**n = 1 is a no-op, so m_e_hat = e_hat and s_e = 1. growth then
  reduces to e_hat ** -k_I, which for k_I large and e_hat < 1 (always -- see G4) overflows past
  GROW and is clipped to it on every step. Clipped-to-GROW on every accepted step IS the ratchet.

========================================================================================
Assumptions of THIS script -- choices that are ours, not the audit's
========================================================================================
   1. Inherits Assumptions 1-8 of adaptive_qite.py and 1-9 of adam_qite.py by construction. Nothing physical is redefined here; this script only re-runs the shipped code and measures.

   2. G5 needs theta_n along the E1 trajectory, which adam_qite_run does not log. Rather than re-implement its step loop -- which would verify the audit against a *copy* of the code, the very defect the audit is about -- theta_n is replayed from the log's own delta_tau plus measure_f. This is valid only because (i) the committed step uses the final post-cap, post-retry delta_tau, which is exactly what log['delta_tau'][n] records, and (ii) nothing but theta and delta_tau carries between steps. check_replay_matches_shipped_log() asserts both, so a future edit breaking either trips an assertion instead of quietly moving a number.

   3. WHAT THE REPLAY CHECK IS AND IS NOT. It is falsifiable -- a post-hoc correction to theta, a logged delta_tau that is the pre-cap rather than the committed value, or any hidden state carried between steps would all make the worst deviation exceed the tolerance. But it is a plumbing check, not physics validation: both the replay and the shipped run call the same measure_f and energy_check, so an error inside either is invisible to it by construction. It licenses target g5's replay premise and nothing more. The non-circular check in this script is the step-doubling comparison in target g5, which puts the module's error estimate against an independently computed one; that one has a target it could have missed, and does not.

   4. THE G5 PROBE COUNT OF 40 IS OURS, RECOVERED BY INFERENCE. The audit records twelve printed rows and five aggregate statistics but never says how many steps V2 probed, and the scratchpad is gone. 40 accepted steps is the prefix that reproduces all five statistics to their recorded digits. The statistics are monotone in the count (see the sensitivity line printed by target g5), so this parameter is load-bearing: it is pinned as the default, not chosen per run. G5 has been amended to record it.

   5. The rule by which the audit selected twelve of those 40 rows to print cannot be recovered. This script prints all 40 instead of inventing a selection rule; the audit's twelve are a subset and can be checked against these by eye.

   6. 'Converged tail' in G5's '2.03-2.09' claim is our operational definition: probed steps 25 through n_probes. The interval is prose-rounded in the note, so the measured [min, max] is printed rather than a pass/fail on the prose.

   7. e_E_true is |E_full - E_two_half| and e_theta is ||theta_full - theta_two_half||_2. The half-step midpoint gets a FRESH measure_f -- that is the circuit cost R1 pays and the reason the estimator under test is free by comparison. The step-doubling arm is a probe only: it never feeds back into the replayed trajectory.

   8. The corrected energy_at_budget cannot be imported (it is the defect under test) and must not be patched into adam_qite.py. energy_at_budget_right() is defined locally and imports circuit_cumsum, so only the single indexing decision is duplicated and the cost model cannot drift from the shipped one. It is a demonstration, not a fix.

   9. G2's V10 table covers SEED_A and SEED_D. Its prose said 'all three seeds'; SEED_C was swept but its rows are omitted for the rcond reason G2 gives, and are no longer reproducible. This script regenerates the two seeds the note actually shows and says so, rather than fabricating a third row. G2 has been amended to match.

  10. variational_floor carries its own seed=12345 and does not depend on theta0, so the audit's two identical E_floor = -1.124600 rows are ONE measurement, not two. Computed once here and printed for both seeds with that stated.

  11. Runs are memoized on (kind, seed, n_params, kwargs), which is safe because each run is a deterministic function of its inputs. check_cache_determinism() re-runs one configuration and asserts identity rather than taking that on trust.

  12. adam_signal_diagnostic is deliberately NOT reused for the sweeps: it closes over the module-level K_I, so its 'ungated k_I' line would mislabel every arm with a swept k_i. arm_stats() computes only the columns the audit reports. This non-reusability is G2's proposed-work item 3.
